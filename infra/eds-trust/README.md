# EDS trust store (корни НУЦ РК)

Каталог доверенных корневых и промежуточных сертификатов **НУЦ РК** для проверки CMS-подписи ЭЦП.
Монтируется в контейнер `ehd-api` как `/app/eds-trust` (см. `docker-compose.dev.yml`), путь берётся из `EDS_TRUST_DIR`.
Используется, когда `EDS_MODE=ncalayer`.

Положите сюда сертификаты в формате **PEM** (`.pem`/`.crt`) или **DER** (`.cer`). Загружаются все файлы каталога.

## Где взять

- **Тестовая зона** (для локальной разработки): тестовые корневые сертификаты и тестовые ключи ЭЦП —
  на портале НУЦ РК, раздел тестовой инфраструктуры (pki.gov.kz). Положите тестовые корни сюда,
  а тестовым ключом подписывайте вход через NCALayer.
- **Продакшн**: действующие корневые/промежуточные сертификаты НУЦ РК с pki.gov.kz.

## Что нужно для реального входа по ЭЦП

1. Установить и запустить **NCALayer** (https://pki.gov.kz/ncalayer/).
2. Положить корни НУЦ РК в этот каталог.
3. Запустить стек с `EDS_MODE=ncalayer`:
   ```bash
   EDS_MODE=ncalayer docker compose -f docker-compose.dev.yml up -d
   ```
   При пустом каталоге `ehd-api` не стартует в режиме ncalayer (осознанная защита).

Сертификаты в репозиторий не коммитятся (кроме этого README).
