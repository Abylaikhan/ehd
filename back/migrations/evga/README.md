# Миграции внешней БД obm_evga (ТЗ §14, EVGA-DB-001…005)

⚠ Это **внешняя боевая БД** другой системы. Скрипты применяются ТОЛЬКО вручную (psql),
из кода не выполняются, AutoMigrate запрещён.

Статус применения:

| Скрипт | dev-реплика | прод |
|---|---|---|
| 001 новые поля (снимок gu/gu_bin; departments notice_num_year) | ✅ 06.09.2026 | ⛔ ждёт согласования |
| 002 in$trash для статусов 3/5/9/10 | ✅ 06.09.2026 | ⛔ |
| 003 журнал its_tb_5_15a_status_log | ✅ 06.09.2026 | ⛔ (обязателен для спеки 008) |
| 004 uniq снимка по tb_5_15a_id | ❌ дубли в данных (даже в сэмпле: tb_5_15a_id=14040247 ×2) | ⛔ БЛОКЕР: в проде запись уже входит в несколько уведомлений — нужен ответ OQ-08 (частичный индекс или чистка) |
| 005 uniq номера уведомления its_req.docnum | ✅ 06.09.2026 (частичный) | ⛔ проверить дубли |

Применение к dev-реплике:

```bash
docker compose -f ../../docker-compose.dev.yml exec -T postgres \
  psql -U ehd -d obm_evga -v ON_ERROR_STOP=1 < back/migrations/evga/00X_*.sql
```

Прод: после письменного подтверждения заказчика, пишущей учётки и бэкапа. Скрипты 004/005
сначала выполняют диагностический SELECT дублей (см. комментарии в файлах).
