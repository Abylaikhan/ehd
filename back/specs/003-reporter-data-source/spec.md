# Спецификация: Reporter — Data Source (источник ClickHouse)

- **ID**: 003-reporter-data-source
- **Статус**: implemented
- **Требования ТЗ**: REP-FR-010, REP-FR-011, REP-FR-012, REP-FR-013, REP-FR-014, REP-BR-001; разделы «Управление источниками ClickHouse», «Просмотр структуры ClickHouse»; раздел 10 (REST `/reporter/admin/sources`)
- **Дата**: 2026-08-24

## 1. Цель и ценность
Первый вертикальный кирпич Reporter Module: единственное **read-only** подключение к ClickHouse, которым администратор управляет из ЕХД. Источник — фундамент для Data View и Query Engine: без него нельзя выбрать базу/таблицу/колонки. Слайс даёт: создание источника с зашифрованным паролем, тест подключения безопасным `SELECT 1`, активацию/деактивацию и интроспекцию структуры (базы → таблицы → колонки). Секрет источника шифруется и никогда не покидает сервер.

## 2. Пользовательские сценарии
- Администратор создаёт **единственный** источник (код, название, host, port, protocol, TLS, username, password) → сохраняется; пароль хранится зашифрованно.
- Администратор (или проверка перед сохранением) запускает тест подключения → безопасный `SELECT 1` → `ok` либо структурированная ошибка; секрет не раскрывается.
- Администратор активирует/деактивирует источник; деактивированный источник не обслуживает пользовательские запросы (проверяется в следующих слайсах).
- Администратор просматривает структуру: список баз (без системных) → таблицы/VIEW/MATERIALIZED VIEW → колонки (имя, ClickHouse-тип, позиция, nullable, комментарий, признаки ключей).
- Не-администратор на `/reporter/admin/*` → 403; запрос без активной сессии → 401.

## 4. Контракты API (раздел 10)
Все маршруты — под сессией администратора; ответы содержат `request_id`; ошибки — единый контракт `{request_id, error:{code,message,details}}`.

Управление источником:
- `POST   /reporter/admin/sources` — создать источник (если активный уже существует — 409).
- `GET    /reporter/admin/sources` — список/единственный источник (без пароля).
- `GET    /reporter/admin/sources/{id}` — карточка источника (без пароля).
- `PATCH  /reporter/admin/sources/{id}` — обновить поля; `password` — опционально (пустой не меняет).
- `POST   /reporter/admin/sources/{id}/test` — тест подключения сохранённого источника.
- `POST   /reporter/admin/sources/test` — тест по переданным параметрам без сохранения секрета.
- `POST   /reporter/admin/sources/{id}/activate` — активировать.
- `POST   /reporter/admin/sources/{id}/deactivate` — деактивировать.

Интроспекция структуры:
- `GET /reporter/admin/sources/{id}/databases` — базы (без системных).
- `GET /reporter/admin/sources/{id}/databases/{db}/tables` — таблицы/VIEW/MATERIALIZED VIEW.
- `GET /reporter/admin/sources/{id}/databases/{db}/tables/{table}/columns` — колонки.

## 5. Сущности данных
`data_sources` (схема `public`): `id` (uuid, pk), `code` (uniq), `name`, `host`, `port`, `protocol` (native|http), `tls_enabled` (bool), `tls_skip_verify` (bool), `username`, `password_enc` (bytea), `status` (active|inactive), `created_at`, `updated_at`.

Инвариант MVP (REP-BR-001): в системе не более одного источника — повторное создание при существующем возвращает 409.

## 6. Нефункциональные ограничения
- Пароль источника — AES-256-GCM через `pkg/crypto`; ключ из окружения. В DTO пароль всегда замаскирован/отсутствует; в zap-логи не пишется.
- ClickHouse — только read-only: `SELECT 1`, `SELECT ... FROM system.*`, `SHOW`, `DESCRIBE`. DDL/DML запрещены (Принцип 3 конституции).
- Имена базы/таблицы в интроспекции — типизированные параметры/идентификаторы; конкатенация пользовательского ввода в SQL запрещена.
- Тест подключения и интроспекция — с таймаутом (≤ 5 c dial, ≤ 15 c запрос); ошибки не раскрывают секрет.
- Metadata API p95 ≤ 500 мс (без учёта латентности внешнего ClickHouse).

## 7. Критерии приёмки
- **AC-1**: `POST /sources` → 201; `GET` не содержит пароль; в БД `password_enc` не читается как текст; пароля нет в логах.
- **AC-2**: `test` с валидными параметрами → `{ok:true}`; с неверными → структурированная ошибка `SOURCE_CONNECTION_FAILED` без утечки секрета.
- **AC-3**: `deactivate` → `status=inactive`; `activate` → `status=active`.
- **AC-4**: `databases` не содержит `system`/`INFORMATION_SCHEMA`/`information_schema` и записи из конфиг-denylist.
- **AC-5**: `columns` для demo-таблицы возвращает имя, тип, позицию, nullable, комментарий.
- **AC-6**: не-администратор на `/reporter/admin/sources` → 403; без сессии → 401.
- **AC-7**: повторный `POST /sources` при существующем источнике → 409 `SOURCE_ALREADY_EXISTS`.

## 8. Вне объёма
- Data View, Query Engine, пользовательская таблица и экспорт (следующие слайсы Reporter).
- Пул подключений per-source и кэш метаданных (оптимизация — позже).
- HTTP(S)-протокол ClickHouse с полной проверкой цепочки сертификатов сверх флага `tls_skip_verify` (MVP: native + флаг TLS).
- Управление несколькими источниками (MVP — один; мультиисточник вне объёма).
