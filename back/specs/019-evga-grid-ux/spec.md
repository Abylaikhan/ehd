# Спека 019 — колоночный поиск и эргономика грида реестра (ОБМ ЭВГА)

Статус: принята (замечания по UI).
Связанные: 007-evga-registry (реестр и фильтры).

## Проблема

В реестре рисков искать можно было только через общую панель фильтров, и то не по всем полям:
для № платежа, ФИО, карт-счёта, комментария и номера исходящего серверного фильтра не было.
Грид читался тяжело: без линий сетки, крупный кегль, шапка уезжала при прокрутке.

## Поведение

### FR-1. Колоночный поиск
`GET /registry` принимает дополнительные параметры подстрочного поиска (регистронезависимо):
`ppo_pp`, `fio` (фамилия/имя/отчество одной строкой), `la1`, `status_note`, `out_num`.
Уже существовавшие `gu` и `iin` переведены с точного совпадения на подстроку —
в колоночном поиске ожидается поиск по части значения.

### FR-2. Строка фильтров в гриде
Под шапкой таблицы — строка поиска по колонкам: текстовые поля для кода ГУ, отправителя,
№ платежа, ИИН, ФИО, карт-счёта, комментария, № уведомления, № исходящего; выпадающие списки
для профиля риска и статуса; дата платежа и сумма — начальные значения диапазона.
Ввод применяется с задержкой 400 мс, поиск серверный (таблица в режиме `lazy`).

### FR-3. Закреплённая шапка
Заголовки колонок и строка фильтров остаются видимыми при прокрутке длинного списка.

### FR-4. Сетка и компактность
Линии между строками и столбцами во всех таблицах приложения. В реестре — уменьшенные
кегль и отступы ячеек, уменьшенная панель фильтров.

### FR-5. Светофор
Отдельная колонка-индикатор контрольного срока: красный — срок истёк, жёлтый — истекает,
зелёный — в пределах срока, серый — срок не применяется (статус без ожидания ответа).

### FR-6. Переименование
В пользовательских текстах и сообщениях «ЕВГА» → «ЭВГА». Технические идентификаторы
(`evga`, `evga_auditor`, `/api/v1/evga`, имена таблиц) не меняются.

## Приёмка

- AT-1: поиск по каждой колонке возвращает отфильтрованный серверный результат.
- AT-2: `gu`/`iin` находят по части значения.
- AT-3: при прокрутке списка шапка и строка фильтров остаются на месте.
- AT-4: во всех таблицах видны линии сетки.
- AT-5: светофор соответствует состоянию срока записи.
- AT-6: в интерфейсе нет строк «ЕВГА».
