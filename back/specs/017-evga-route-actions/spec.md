# Спека 017 — доступность действий маршрута по ролям (ОБМ ЕВГА)

Статус: принята (запрос пользователя).
Связанные: 010-evga-approval (согласование), 011-evga-outgoing (исходящее).

## Проблема

Кнопки «Ход исполнения» показывались всем, у кого есть право записи в модуле, по одному лишь
статусу заявки. В результате:
- **согласующий** видел кнопку «Создать исходящее», хотя этот этап назначен другому;
- **инициатор** (создатель маршрута) видел «Согласовать и подписать» / «Вернуть на доработку»,
  хотя согласующим указан не он.

Сервер такие вызовы отклоняет (`ErrNotAssignee`, 403), то есть права не нарушались, но UI
предлагал заведомо недоступные действия.

## Решение

Доступность действий вычисляет **бэкенд** и отдаёт в ответе маршрута; фронт только показывает
или скрывает кнопки (права не расширяет).

### FR-1. Признаки в ответе `GET /notices/:id/route`
- `can_approve` — текущий пользователь может согласовать/вернуть на доработку;
- `can_create_outgoing` — может создать исходящее.

### FR-2. Правила вычисления
Оба признака требуют включённого режима записи (`EVGA_WRITE_ENABLED`) и повторяют авторизацию
соответствующих операций:
- `can_approve` = статус заявки «На согласовании» **и** открытый шаг типа `approve`
  **и** текущий пользователь — исполнитель этого шага. Исключения для администратора нет
  (подписывает только назначенный согласующий).
- `can_create_outgoing` = статус «На подписании» **и** открытый шаг типа `outgoing`
  **и** (текущий пользователь — исполнитель шага **или** администратор).

### FR-3. UI
Кнопки «Согласовать и подписать» / «Вернуть на доработку» показываются только при `can_approve`;
«Создать исходящее» — только при `can_create_outgoing`. Дополнительно сохраняется прежняя
проверка роли на запись (куратор кнопок не видит).

## Приёмка

- AT-1: согласующий на этапе согласования не видит «Создать исходящее».
- AT-2: инициатор, не указанный согласующим, не видит «Согласовать»/«Вернуть».
- AT-3: назначенный согласующий видит «Согласовать»/«Вернуть».
- AT-4: ответственный за исходящее (обычно инициатор) видит «Создать исходящее» на этапе «На подписании».
- AT-5: куратор не видит ни одной кнопки действий.
