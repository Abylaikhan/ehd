description: Проверить согласованность spec/plan/tasks и соответствие конституции
argument-hint: <NNN или slug фичи>
---

Аудит перед реализацией `specs/$ARGUMENTS/` (read-only).

Отчёт:

1. **Трассировка**: каждое требование spec → задача; каждая задача → требование. Сироты с обеих сторон.
2. **Конституция** (7 принципов): PrimeVue-only, токены (не inline), Nuxt Layers, сервер-стейт не в Pinia, фронт не расширяет права, обязательные состояния экрана, тесты.
3. **Галлюцинации**: все упомянутые компоненты/composables/файлы существуют — подтверди `graphify_locate` (не Grep). Поля API — из типов `shared/api`.
4. **Покрытие**: состояния Loading/Empty/Error/Access denied; a11y (focus, aria, смысл не цветом); критерии приёмки измеримы.
5. Противоречия spec ↔ plan ↔ tasks.

Формат: `Находка | Серьёзность (blocker/major/minor) | Где | Рекомендация`. Blocker → «реализацию начинать нельзя».
