# §8. Этап 4. Формирование уведомления

**Исполнитель:** аудитор ДВГА. **Точка входа:** кнопка «Сформировать уведомление» в реестре.

## Условия включения записи

- **EVGA-FR-030.** В уведомление попадают записи: статус = 1 «В работе у ДВГА»; не входящие ни в одно действующее уведомление; принадлежащие департаменту текущего пользователя. Не удовлетворяющие — выводятся отдельным списком с причиной.

## Группировка

- **EVGA-FR-031.** Отмеченные записи группируются по коду ГУ (`its_tb_5_15a.gu`). **Каждая группа = отдельное уведомление**; объединение разных ГУ не допускается.
- **EVGA-FR-032.** Экран группировки — таблица: Код ГУ | Наименование отправителя | Кол-во записей | Общая сумма | Адресат (*выбрать из ЕСЕДО*) | Действие (исключить).
- **EVGA-FR-033.** Адресат выбирается вручную для каждой группы из `its_cli` — поиск по наименованию и коду.
- **EVGA-FR-034.** Кнопка «Создать» неактивна, пока хотя бы у одной группы не выбран адресат.
- **EVGA-FR-035.** Любую группу можно исключить — её записи остаются в реестре в прежнем статусе.
- **EVGA-FR-036.** Записи с пустым `gu` в группировку не попадают, выводятся отдельным блоком с ошибкой.

## Создаваемые объекты (по каждой группе)

- **EVGA-FR-037.** `its_risk_notice` — шапка: `its_departments_id` (департамент аудитора), `created_by` (инициатор), `notice_txt` (из шаблона), `exec_due_time` (10 рабочих дней с даты регистрации исходящего), номер — присваивается при отправке на согласование (§12), статус «Проект создан».
- **EVGA-FR-038.** `its_risk_notice_5_15a` — снимок каждой строки группы: `tb_5_15a_id`, `its_risk_profile_id`, `gu`, `gu_bin`, `ppo_pp`, `paymentdate`, `iin`, `fm`, `nm`, `ft`, `la1`, `amount_part`, `sendername`. Снимок принципиален: пересчёт витрины не должен менять состав/содержание отправленного документа.
- **EVGA-FR-039.** `its_risk_notice_recepient` — выбранный адресат (`its_cli_id`).

## Замечание по модели данных

В `its_risk_notice_5_15a` два FK на одну таблицу: `tb_5_15a` и `tb_5_15a_id`; фактически заполняется только `tb_5_15a_id`. **Рабочее поле — `tb_5_15a_id`**; `tb_5_15a` не заполнять, вынести в техдолг на удаление.
