# §1–4. Назначение, термины, роли, таблицы

**Система:** ОБМ ЕВГА (`10.58.57.39`, БД `obm_evga`, схема `public`). Версия ТЗ 1.0 (черновик), 02.09.2026.

## Назначение

Полный цикл работы аудитора ДВГА с результатами онлайн-бюджетного мониторинга: простановка статуса
по записи витрины рисков `its_tb_5_15a` → формирование уведомления об устранении нарушения →
согласование → подписание ЭЦП → регистрация канцелярией → отправка объекту контроля через ЕСЕДО →
фиксация результата отработки.

## Термины

| Термин | Расшифровка |
|---|---|
| КВГА | Комитет внутреннего государственного аудита МФ РК |
| ДВГА | Департамент внутреннего государственного аудита по области (терорган КВГА) |
| Витрина 5-15а | Таблица `public.its_tb_5_15a` — результаты расчёта профилей риска |
| Запись риска | Строка витрины: один платёж в разрезе одного профиля риска |
| Уведомление | Документ «Уведомление об устранении нарушения» объекту контроля |
| Исходящее письмо | Документ канцелярии, которым уведомление направляется адресату |
| ГУ | Государственное учреждение — отправитель платежа (`its_tb_5_15a.gu`) |
| Адресат | Организация-получатель письма из справочника ЕСЕДО (`its_cli`) |
| ЕСЕДО | Единая система электронного документооборота госорганов |

## Роли

| Роль | Полномочия |
|---|---|
| Система (робот публикации) | Наполнение витрины, автоматические технические статусы |
| Аудитор ДВГА (исполнитель) | Реестр своего департамента: просмотр, фильтры, статусы (одиночно/массово), формирование уведомлений, маршрут, отправка на согласование, отработка ответов ГУ |
| Согласующий (подписант) | Сотрудник департамента аудитора (обычно руководитель/зам). Согласует и подписывает ЭЦП либо возвращает на доработку. Назначается в маршруте, жёсткой привязки к должности нет |
| Канцелярия ДВГА | Регистрация исходящего (№ и дата) и отправка. Работает **на стороне ЕСЕДО**, в маршруте не участвует |
| Куратор КВГА | Просмотр реестра и уведомлений всех департаментов, read-only |
| Администратор | Справочники, шаблон текста уведомления, счётчики нумерации |

## Задействованные таблицы `obm_evga.public`

| Таблица | Роль |
|---|---|
| `its_tb_5_15a` | Витрина рисков |
| `its_risk_status` | Справочник статусов записи |
| `its_risk_profile` | Профили риска (`query_text` — расчёт, `risk_desc` — описание) |
| `its_departments` | Департаменты ДВГА, реквизиты письма, счётчик нумерации |
| `its_regions` | Регионы, код региона для номера уведомления |
| `its_risk_notice` | Шапка уведомления |
| `its_risk_notice_5_15a` | Снимок строк уведомления (приложение) |
| `its_risk_notice_recepient` | Адресаты уведомления (→ `its_cli`) |
| `its_cli` | Справочник организаций ЕСЕДО |
| `its_out` | Исходящее письмо |
| `its_activity` | Аудиторские мероприятия (для статуса «Аудит») |
| `files` | Хранение PDF (S3) |
| `users` | Пользователи: департамент и реквизиты исполнителя |
