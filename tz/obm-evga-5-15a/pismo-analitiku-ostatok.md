## Вопрос. Где в бланке уведомления печатать код ДВГА?

Вы писали: «Шаблон документа привести в порядок (14 размер, Таймс Нью Роман,
**отсутствует код ДВГА**)». Шрифт и размер сделали.

**Мы нашли и исправили свою ошибку.** В бланке печаталось
«ДВГА по Жетісу КВГА МФ РК **(код 19)**». 19 — это код региона, а не код ДВГА;
мы подставляли его, когда у департамента нет своего кода. В официальном документе
это неверно, подстановку убрали.

**Что в данных.** Код ДВГА существует, это 5-значный бюджетный код:

| Департамент | Код |
|---|---|
| ДВГА по Туркестанской области | 35801 |
| ДВГА по Жамбылской области | 32101 |
| ДВГА по Акмолинской области | 30301 |
| **ДВГА по Жетісу** | **кода нет** |
| По Абайской области, по Павлодарской области, по области Улытау | кода нет |

Код заполнен у **18 департаментов из 22**. У четырёх новых областей, включая Жетісу,
его нет — поэтому на тестовом стенде код не отображается.

Сейчас сделано так: код есть — печатаем в подвале рядом с наименованием департамента
(«ДВГА по Туркестанской области КВГА МФ РК (код 35801)»); кода нет — печатаем только
наименование, как в переданном вами образце.

**Просим ответить:**

1. **Где именно** должен стоять код — в шапке рядом с наименованием департамента,
   в подвале (как сейчас), в номере уведомления, или печатать его не нужно?
   В вашем образце `Уведомление_об_устранении_нарушения.pdf` кода нет нигде,
   поэтому сами выбрать место мы не можем.
2. **Что делать с четырьмя департаментами без кода** — оставлять пустым, или код нужно
   завести в справочнике? Если завести — подскажите, кто это делает.

## Подтверждение 1. Автоматические статусы повторяющимся рискам — НЕ делаем

Замечание 5: при отработке риска статус должен автоматически присваиваться
**повторяющимся рисковым платежам**. Мы проверили оба возможных понимания «повторения»
на боевой базе — **данные показывают, что аудиторы так не работают**.

**Понимание 1: повторение — другое замечание по тому же платежу.**
Из 1 023 016 платежей с несколькими замечаниями **112 222 (11%) уже имеют разные статусы**
по разным замечаниям.

**Понимание 2: то же нарушение у того же получателя в другом месяце.**
Таких повторений 649 874. Там, где аудитор принял минимум два решения:

| | |
|---|---|
| статус оказался одинаковым | 56 611 (**35%**) |
| статус оказался **разным** | 103 764 (**65%**) |

То есть при любом понимании автоматический перенос статуса был бы **ошибочным
в большинстве случаев**. Это совпадает с вашим замечанием 1, где вы просили дать
возможность отрабатывать каждый риск отдельно.

**Что сделано:** автоматический перенос статуса отключён.

**Что предлагаем вместо:** при смене статуса показывать аудитору подсказку
«по такому же нарушению ранее был статус "Не подтверждено" (14 раз)» — решение
остаётся за человеком. Сделаем, если нужно.

**Просим подтвердить:** автоматический перенос статусов не возвращаем, замечание 5 закрываем.
