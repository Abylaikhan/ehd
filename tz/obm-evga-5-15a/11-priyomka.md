# §15. Сценарии приёмочного тестирования

| № | Сценарий | Ожидаемый результат |
|---|---|---|
| AT-01 | Аудитор департамента А открывает реестр | Видны только записи `its_departments_id` департамента А |
| AT-02 | Повторная публикация витрины при наличии записей со статусами | Статусы, комментарии, суммы возмещения и ссылки сохранены; расчётные поля обновлены |
| AT-03 | Перевод записи из статуса 4 в 1 | Отклонён с сообщением |
| AT-04 | Перевод в статус 2 без комментария | Заблокировано, требуется `risk_status_note` |
| AT-05 | Перевод в статус 8 при `refund < amount_for_vozvrat` | Отклонён, запись остаётся в 7 |
| AT-06 | Массовая простановка по 50 записям, 5 в недопустимом статусе | Обработано 45, отклонено 5, перечень с причинами |
| AT-07 | Формирование уведомления по записям 3 разных ГУ | 3 уведомления, у каждого свой адресат и номер |
| AT-08 | Создание уведомления без адресата у одной из групп | Кнопка «Создать» неактивна |
| AT-09 | Отправка на согласование без согласующего | Кнопка неактивна, сообщение о недостающем этапе |
| AT-09а | Открытие вкладки «Маршрут» нового уведомления | «Создать исходящее» предзаполнен инициатором; в списке — только сотрудники своего департамента |
| AT-10 | Два аудитора одновременно отправляют на согласование | Номера различны, пропусков нет |
| AT-11 | Первое уведомление департамента после 1 января | Номер `<регион>/<новый год>/000001` |
| AT-12 | Возврат на доработку и повторная отправка | Номер не изменился |
| AT-13 | Смена подписанта после возврата на доработку | В финальном PDF фактический подписант |
| AT-14 | Регистрация исходящего канцелярией | Записи → статус 4, ссылки проставлены, срок 10 раб. дней рассчитан, уведомление «Исполнен» |
| AT-15 | Изменение состава строк в статусе «На согласовании» | Недоступно |
| AT-16 | Сверка PDF с образцом | Совпадение структуры, колонок, форматов, шапки и подвала |
| AT-17 | Пересчёт витрины после отправки уведомления | Содержание сформированного PDF не изменилось |
