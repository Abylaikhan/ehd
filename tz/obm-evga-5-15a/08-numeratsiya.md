# §12. Нумерация

## Номер уведомления

- **EVGA-FR-070.** Формат: `<код региона>/<год>/<порядковый номер>` → `11/2026/001097`; порядковый — 6 знаков с ведущими нулями.
- **EVGA-BR-020.** Код региона — из `its_regions.region_code` (НЕ `its_regions.code`, НЕ первые цифры КАТО). Проверено по данным: Кызылординская область `code=43`, `kato=430000000`, `region_code=11` — и именно 11 в номерах. Связь: `its_departments.its_regions_id → its_regions.region_code`.
- **EVGA-FR-071.** Номер присваивается при нажатии «Отправить на согласование», не при создании черновика (удалённые проекты не образуют пропусков).
- **EVGA-FR-072.** Счётчик — `its_departments.notice_num` (последний использованный). Выдача в транзакции с блокировкой строки департамента: `select notice_num from its_departments where id = ? for update` → +1 → `update` → присвоение.
- **EVGA-BR-021.** Блокировка обязательна: без неё два одновременных аудитора получат одинаковый номер (AT-10).
- **EVGA-FR-073.** Счётчик сбрасывается с 1 января (нумерация с 000001): в `its_departments` добавляется поле года последней выдачи (EVGA-DB-001); если год ≠ текущему — счётчик обнуляется и год обновляется в той же транзакции.
- **EVGA-FR-074.** При повторной отправке после доработки номер сохраняется, повторно не выдаётся.

## Номер исходящего письма

- **EVGA-FR-075.** Формат `03-1-11/835`. Присваивается канцелярией при регистрации в ЕСЕДО. Система его не генерирует — принимает и сохраняет в `its_out` вместе с датой регистрации.
- **EVGA-BR-022.** Риск: если в одном регионе несколько департаментов — счётчики независимы, номера задублируются (OQ-09).
- **EVGA-BR-023.** Запись `its_regions` «Южно-Казахстанская область» (`region_code=99`) устарела — исключить из выбора либо `in$trash=1` (OQ-10).
